### 在做的事

一堆 AI 编程 CLI 各说各话：配额是各自的、凭据是各自的、上下文也是各自的。
换个工具，配置重来一遍，项目背景再解释一遍。

我的项目基本都在补这中间的缝：

**统一入口** — 把 Gemini CLI、Codex、Claude Code、Qwen 包装成同一套 OpenAI 兼容 API，配额和凭据集中管，前面再挂个面板能看能调。

**统一记忆** — 让 agent 自己判断什么值得长期留存，写进本地知识库；换工具、换模型的时候，理解还在。

工程上偏执两件事：**离线可用**（能跑在本地的绝不依赖云端）和**数据归属**（不做账号、不做同步、不埋遥测）。
